## 🔍 Visão Geral

**CipherForge AO** é um toolkit de cibersegurança interativo, cross-platform e de linha de comando desenvolvido pela **AOFR TECH**, projetado para profissionais de segurança, pentesters, analistas de Blue Team, operadores de Red Team e estudantes de cibersegurança.

O toolkit oferece **9 áreas especializadas** com centenas de comandos, cenários reais, checklists e referências rápidas — tudo num único script Python sem dependências pesadas.

## 🔐 Área 09 — Ferramentas de Quebra de Senhas

A área de destaque do CipherForge AO cobre as **12 principais ferramentas de auditoria de senhas** utilizadas em cibersegurança profissional:

```
🐱 Hashcat        —  Recuperação offline com aceleração GPU (NTLM, Kerberos, WPA2, JWT)
🐉 Hydra          —  Brute force de login de rede (SSH, HTTP, RDP, FTP, MySQL, SMTP)
🧠 Medusa         —  Login paralelo de alta velocidade em múltiplos alvos
🦂 Ncrack         —  Cracking de autenticação de rede (família Nmap)
🕵️ John the Ripper —  Auditoria offline (shadow, ZIP, PDF, SAM, SSH keys)
🐙 Wfuzz          —  Fuzzing e brute force para aplicações web
📡 Aircrack-ng    —  Auditoria completa de redes Wi-Fi 802.11 (WPA2/PMKID)
👾 CrackMapExec   —  Validação de credenciais e pós-exploração em AD
💻 Ophcrack       —  Rainbow tables para hashes Windows LM/NTLM
⚡ L0phtCrack     —  Auditoria enterprise de senhas Windows
🛡️ Brutus         —  Ferramenta clássica de autenticação remota
🌈 RainbowCrack   —  Sistema de quebra com tabelas rainbow customizadas
```

## 🚀 Início Rápido

### Pré-requisitos

- Python 3.10 ou superior
- Terminal com suporte a cores ANSI (CMD/PowerShell Windows 10+ · Bash/Zsh Linux/macOS)

### Instalação

```bash
# Clonar o repositório
git clone https://github.com/AOFR-TECH/cipherforge-ao.git
cd cipherforge-ao

# Sem dependências externas obrigatórias — apenas Python stdlib
python3 cipherforge_ao.py

# Dependências opcionais (para funcionalidades avançadas)
pip install requests paramiko
```

### Uso

```bash
# Abrir menu interativo completo
python3 cipherforge_ao.py

# Aceder directamente a uma área
python3 cipherforge_ao.py 1    # Analista de Segurança
python3 cipherforge_ao.py 6    # Testador de Penetração
python3 cipherforge_ao.py 9    # Ferramentas de Quebra de Senhas

# Windows
python cipherforge_ao.py
python cipherforge_ao.py 9
```

## 🛠️ Ferramentas Externas Suportadas

O CipherForge AO detecta automaticamente as ferramentas instaladas e adapta os comandos. As seguintes ferramentas são referenciadas:

**Reconhecimento:** `nmap` · `masscan` · `theHarvester` · `gobuster` · `ffuf`

**Web:** `sqlmap` · `wfuzz` · `burpsuite` · `nikto`

**Passwords:** `hashcat` · `john` · `hydra` · `medusa` · `ncrack` · `aircrack-ng` · `hcxdumptool`

**Active Directory:** `crackmapexec` / `nxc` · `impacket` · `bloodhound-python` · `rubeus`

**Forense:** `volatility` · `autopsy` · `exiftool` · `strings` · `binwalk`

**Malware:** `yara` · `radare2` · `ghidra` · `clamav`

**C2 / Red Team:** `sliver` · `metasploit` · `gophish`

## 📚 Casos de Uso Profissionais

### 🔵 Blue Team / SOC
- Monitorização de eventos com comandos SIEM prontos
- Threat hunting com IOCs e regras Sigma/YARA
- Análise de logs e correlação de eventos

### 🔴 Red Team / Pentest
- Reconhecimento OSINT automatizado
- Exploração de Active Directory (Kerberoasting, AS-REP Roasting)
- Password spraying e pass-the-hash
- Simulação de APT com C2 frameworks

### 🟣 Forense Digital
- Colecta de artefactos IR cross-platform
- Análise de dumps de memória RAM
- Preservação de evidências com chain of custody

### 🔐 Auditoria de Senhas
- Identificação de senhas fracas em Active Directory
- Auditoria de redes Wi-Fi corporativas
- Validação de políticas de password

## 🏆 Por que CipherForge AO?

- **🇦🇴 Made in Angola** — Desenvolvido por e para profissionais angolanos de cibersegurança
- **⚡ Zero dependências obrigatórias** — Corre imediatamente com Python puro
- **🌐 Cross-platform real** — Não é apenas "funciona no Linux" — foi construído para Windows também
- **📋 Modo DRY-RUN** — Comandos destrutivos ou sensíveis são exibidos sem executar, garantindo segurança operacional
- **🎯 Cenários reais** — Cada área inclui um cenário real baseado no contexto angolano/africano
- **📖 Educacional** — Cada comando tem explicação, contexto e alternativas
